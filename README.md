# openrockets.com

Recovered website source for **openrockets.com**.

The repository root is the website root:

- `index.html` — homepage
- `join.html` — join page
- `team/`, `merch/`, `research/`, `magazinesoftware/`, `our-communities/` — recovered routes
- `assets/`, `i/`, `v/`, `26/`, `styles/` — recovered same-domain static assets
- `.github/workflows/pages.yml` — publishes the root site to the `gh-pages` branch
